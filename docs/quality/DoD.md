# Definition of Done (DoD)

## DoD para Historia de Usuario
- [ ] Criterios de aceptación claros y verificables.
- [ ] CTQ asociado cuando aplica.
- [ ] Código implementado en rama de trabajo.
- [ ] Pruebas manuales o automáticas documentadas.
- [ ] Evidencia registrada en el issue.

## DoD para Pull Request
- [ ] PR vinculado a issue del backlog.
- [ ] Quality Gate ejecutado.
- [ ] No existen fallas críticas abiertas.
- [ ] README o documentación actualizada si cambia el comportamiento.
- [ ] Revisión de al menos un integrante del equipo.

## DoD para Sprint/Release
- [ ] CTQs Must completados o justificados.
- [ ] Deuda técnica registrada como issue.
- [ ] Evidencias consolidadas en docs/quality/QualityGate.md.
- [ ] Versión etiquetada o release note preparada.
